FFH4X — SITE ESTÁTICO

Arquivos na raiz da pasta:
- index.html: estrutura do site
- style.css: visual e responsividade
- script.js: menu móvel e efeitos leves
- ffh4x-logo.png: imagem enviada usada no design

Como visualizar:
1. Extraia o ZIP.
2. Abra a pasta "site".
3. Abra o arquivo index.html no navegador.

Para publicar:
Envie todos os arquivos da pasta "site" para a raiz do seu serviço de hospedagem estática.

Os botões apontam para os três links fornecidos. O site não hospeda os arquivos de download nem controla os serviços externos.
